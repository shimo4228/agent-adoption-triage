# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-07-02

Initial release as a standalone skill repository.

### Added

- `skills/agent-adoption-triage/SKILL.md` — a five-question triage (Q0 phase, Q1 deterministic, Q2 static-finite, Q3 workflow-drawable, Q4 gap-bearer + Phase-crossing decision) routing AI work to one of the four Business AI Quadrants; per-quadrant governance sets with redirect paths; hybrid architecture guidance; a 10-item anti-patterns checklist with recovery paths; and a triage record template.

### Notes

- This is the installable publication of the adoption navigator maintained in the [Agent Attribution Practice](https://github.com/shimo4228/agent-attribution-practice) research repository (`docs/quadrants/` — decision tree, governance mapping, case studies, anti-patterns). The paired decision records [AAP ADR-0009 (Triage Before Autonomy) and ADR-0010 (Phase Separation)](https://github.com/shimo4228/agent-attribution-practice/tree/main/docs/adr) stay in the research repository.
- This repository is manually curated: improvements flow here editorially from the AAP navigator. There is intentionally no automated sync script.
